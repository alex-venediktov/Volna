---
description: Дописать запись в журнал активной задачи (или показать журнал, если без аргумента)
argument-hint: [что записать]
---

Аргумент `$ARGUMENTS` **есть** — допиши это в журнал активной задачи по формату скилла
`volna-journal`: в секцию текущего этапа, разложив по подпунктам (что / зачем / почему / как /
сделано / осталось / нужно). Если запись относится к вопросу, требующему человека — добавь её
и в `open[]` frontmatter.

Аргумента **нет** — покажи журнал активной задачи: frontmatter целиком и заголовки секций со
сводкой в одну строку каждая. Полный текст секций выводи только по отдельной просьбе — это
дорого по контексту.

Прошлые секции не переписывай.
