Перейди к этапу **deliver** активной задачи: коммит, задача-фикс, push, PR — одним этапом.

1. Прочитай `skills/volna-flow/stages/deliver.md` — **только этот файл**, не весь набор — и
   выполняй его.
2. Обнови `stage` во frontmatter журнала и отметку в трекере задач сессии. Секцию этапа в логе
   открой **до `git commit`**: без записи по текущему этапу hook `gate.mjs` коммит не пропустит.
   В конце этапа допиши её результатом и перепиши `## Состояние`.

Этап уровня **required**: коммит, push и создание PR необратимы или видны другим людям. Спроси
**вариантами** один раз на всю доставку, с опцией «вернусь и посмотрю» — трёх подтверждений
подряд не задавай. Автопроходом в этап не входят: цепочка `intake` → `visual` кончается перед ним.
Для bug задача-фикс создаётся **до** push, чтобы в PR стоял её номер, а не номер бага. Сообщение
коммита — по скиллу `volna-craft:commit-style`.
