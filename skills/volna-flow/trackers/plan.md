# Трекер · plan — пометить задачу активной

Открывается на `plan` при заполненной строке профиля `трекер`. Профиль `трекер: нет` или
`mode: local` — шага нет вовсе: статус ставить некуда.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-tracker.mjs | sort -V | tail -1
```

## Команда

```
node <плагин>/bin/volna-tracker.mjs state <id> в-работе
```

- `в-работе` — статус по смыслу: имя в трекере команда берёт из секции «## Статусы трекера»
  `.volna/project.md`, без строки — умолчание шлюза. Ни строки, ни умолчания — команда отказывает
  и называет, что дописать; имя статуса как есть (`"В работе"`) уходит в трекер без перевода;
- статус ставится на задачу из `state.json` (у бага — на сам баг): задача-фикс появится только на
  `deliver`;
- задача уже в работе или дальше → сказать об этом человеку и оставить как есть;
- допустимые статусы показывает `states`; аргумент у трекеров свой: TFS — тип задачи, Jira — ключ
  (доступные переходы) или тип, task-tracker — без аргумента;
- трекер не ответил — статус не поставлен, строка в `open[]`, работа идёт дальше: статус обратим и
  ставится на `close`.

## Специфика трекера

| Трекер | Файл | Что там |
|---|---|---|
| `tfs` | нет | — |
| `jira` | `trackers/jira/plan.md` | недоступный переход рабочего процесса |
| `task-tracker` | нет | — |
