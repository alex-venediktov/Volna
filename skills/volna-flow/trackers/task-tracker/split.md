# task-tracker · split — ребёнок задачей трекера

Открывается на `/volna:split`, когда человек выбрал детей в трекере. Родитель — задача трекера
(`mode: tracker`); у локального родителя в трекере нет задачи, и дети остаются локальными.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-tracker.mjs | sort -V | tail -1
```

## Команды, по паре на ребёнка

```
node <плагин>/bin/volna-tracker.mjs create <вид> --title "<заголовок>" --parent <id родителя> \
     [--body-file <постановка>]
node "${CLAUDE_PLUGIN_ROOT}/bin/volna-task.mjs" add <родитель> --tracker <id из ответа> \
     --title "<заголовок>" --goal "<постановка>"
```

- **вид** — `bug`, `task` или `research`: от него префикс id (`bugfix`, `feature`, `research`), номер
  — наибольший на сервере плюс 1, один на все проекты. Id собирает CLI, вручную его не задавать;
- **связи у сервера нет**: `--parent` пишет `родитель: <id>` первой строкой постановки ребёнка и
  комментарий `ребёнок: <id>` у родителя. Очередь детей держит журнал «Волны» (`children`);
- **сначала задача, потом журнал**: `add` сети не имеет и принимает id готовой задачи. Задача
  создана, а `add` отказал — повторить только `add`, вторую задачу не заводить;
- отменённого ребёнка не удаляют (удаления нет), а переводят в `done` с комментарием.
