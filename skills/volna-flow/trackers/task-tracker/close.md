# task-tracker · close — статус и итог

Открывается на `close` при профиле `трекер: task-tracker` в ветвях А-В. Ветвь Г (`mode: local`,
`трекер: нет`, `закрытие: журнал`) файл не открывает: в трекер не уходит ничего.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-tracker.mjs | sort -V | tail -1
```

## Команды

```
node <плагин>/bin/volna-tracker.mjs comment <id> --body-file <файл>
node <плагин>/bin/volna-tracker.mjs state <id> закрыта
```

## Порядок и правила

- **часов, оценки и исполнителя у сервера нет**: `time` и `estimate` отвечают кодом 4 «шлюз не
  умеет» — шаг не делается. Часы и итог идут в журнал, как в ветви Г;
- итог работы — **комментарием**, до смены статуса: постановка принадлежит постановщику;
- `закрыта` становится `done`; `review` флоу не ставит — задача идёт из `doing` сразу в `done`;
- удаления у сервера нет: ненужную задачу переводят в `done` с комментарием о причине;
- **одно изменение — одно подтверждение**; показать, что уйдёт, не отправляя, — `--dry-run`.
