# task-tracker · plan — пометить задачу активной

Открывается на `plan` при профиле `трекер: task-tracker`. Профиль `трекер: нет` или `mode: local` —
шага нет вовсе: статус ставить некуда.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-tracker.mjs | sort -V | tail -1
```

## Команда

```
node <плагин>/bin/volna-tracker.mjs state <id> в-работе
```

- статус по смыслу `в-работе` становится `doing`: набор статусов у сервера постоянный (`backlog`
  `todo` `doing` `review` `done`), переходов и запретов нет — задачу можно перевести из любого;
- сервер недоступен — статус не поставлен, строка в `open[]`, работа идёт дальше: статус обратим и
  ставится на `close`.
