# Jira · plan — пометить задачу активной

Открывается на `plan` при профиле `трекер: jira`. Профиль `трекер: нет` или `mode: local` —
шага нет вовсе: статус ставить некуда.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-jira.mjs | sort -V | tail -1
```

## Команда

```
node <плагин>/bin/volna-jira.mjs state <ключ> "В работе"
```

- **статус меняется переходом рабочего процесса, а не записью поля**: из текущего статуса
  доступны не все статусы. Команда принимает и имя перехода, и имя целевого статуса;
- переход недоступен → команда печатает список доступных переходов и ничего не меняет. Это не
  сбой: рабочий процесс не пускает из текущего состояния. Сказать это человеку и спросить, каким
  переходом идти;
- посмотреть, что доступно сейчас: `states <ключ>`; все статусы типа задач: `states <тип>`;
- статус ставится на задачу из `state.json`; задача-фикс в Jira не заводится (см. `deliver.md`).
