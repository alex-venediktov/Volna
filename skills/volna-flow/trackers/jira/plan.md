# Jira · plan — особенности

Открывается после `trackers/plan.md` при профиле `трекер: jira`.

- **статус меняется переходом рабочего процесса, а не записью поля**: из текущего статуса
  доступны не все статусы. `state` принимает и имя перехода, и имя целевого статуса;
- **у шлюза нет умолчаний статусов по смыслу**: имена свои у каждого проекта. Строки
  «в работе» в «## Статусы трекера» нет — взять имя из `states <ключ>` и предложить человеку
  дописать строку;
- переход недоступен → команда печатает список доступных переходов и ничего не меняет. Это не
  сбой: рабочий процесс не пускает из текущего состояния. Сказать это человеку и спросить, каким
  переходом идти.
