# Jira · split — ребёнок дочерней задачей

Открывается на `/volna:split`, когда человек выбрал детей в трекере. Родитель — задача трекера
(`mode: tracker`); у локального родителя в трекере нет задачи, и дети остаются локальными.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-jira.mjs | sort -V | tail -1
```

## Команды, по паре на ребёнка

```
node <плагин>/bin/volna-jira.mjs create "<тип>" --title "<заголовок>" --parent <ключ родителя> \
     --estimate <часы> [--body-file <постановка>]
node "${CLAUDE_PLUGIN_ROOT}/bin/volna-task.mjs" add <родитель> --tracker <ключ из ответа> \
     --title "<заголовок>" --goal "<постановка>"
```

- **тип ребёнка зависит от родителя**: у задачи — подзадача, у эпика — задача. Имя типа в
  проекте своё (`Sub-task`, `Subtask`, `Подзадача`), его не угадывать: непринятый тип команда
  отклоняет и печатает типы проекта;
- проект берётся из ключа родителя; исполнитель — текущий пользователь (`--no-assign` — без него);
- **сначала задача, потом журнал**: `add` сети не имеет и принимает ключ готовой задачи. Задача
  создана, а `add` отказал — повторить только `add`, вторую задачу не заводить;
- одно заведение — одно подтверждение не нужно: состав детей человек уже принял одним «да».
