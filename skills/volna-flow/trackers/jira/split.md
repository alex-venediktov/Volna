# Jira · split — особенности

Открывается после `trackers/split.md` при профиле `трекер: jira`.

- **тип ребёнка зависит от родителя**: у задачи — подзадача, у эпика — задача. Имя типа в
  проекте своё (`Sub-task`, `Subtask`, `Подзадача`), его не угадывать: непринятый тип команда
  отклоняет и печатает типы проекта;
- проект берётся из ключа родителя; исполнитель — текущий пользователь (`--no-assign` — без него).
