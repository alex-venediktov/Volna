# TFS · split — особенности

Открывается после `trackers/split.md` при профиле `трекер: tfs`.

- тип ребёнка — `Task`; `--like <id соседней задачи>` снимает обязательные поля процесса;
- ребёнок бага — дочерний `Task`, то есть уже задача-фикс: на его `deliver` второй задачи-фикса не
  создаётся, `fix_task` пуст, номер в PR — его собственный;
- исполнитель, обязательные поля и оценка — как у задачи-фикса (`trackers/tfs/deliver.md`,
  «Задача-фикс»).
