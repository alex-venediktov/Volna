# TFS · intake — прочитать задачу

Открывается на `intake` при профиле `трекер: tfs`. Профиль `трекер: нет` или `mode: local` —
файл не нужен: читать нечего.

Работа с трекером идёт через CLI плагина, а не сырым REST. Путь:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-tfs.mjs | sort -V | tail -1
```

(или готовая команда из `.volna/project.md`).

## Прочитать задачу

```
node <плагин>/bin/volna-tfs.mjs get <id>
```

Отдаёт заголовок, тип, состояние, описание, связи и комментарии обсуждения одним компактным
markdown. Команда читающая, подтверждения не требует.

## Вложения

```
node <плагин>/bin/volna-tfs.mjs attachments <id> --out <каталог>
```

Анонимно трекер отдаёт 401 — команда качает PAT'ом. Ссылку из описания браузером не открывать:
без авторизации вернётся страница входа, а не файл.

## Что взять из ответа

Тип (`Bug` / `User Story` / `Task`) определяет ветвление флоу. Для бага — ещё и родительскую US:
постановка чаще там, а не в самом баге.
