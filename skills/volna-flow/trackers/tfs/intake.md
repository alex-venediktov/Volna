# TFS · intake — особенности

Открывается после `trackers/intake.md` при профиле `трекер: tfs`.

Тип задачи — `Bug` / `User Story` / `Task`; родитель бага — обычно US.

## Вложения

```
node <плагин>/bin/volna-tracker.mjs attachments <id> --out <каталог>
```

Анонимно трекер отдаёт 401 — команда качает PAT'ом. Ссылку из описания браузером не открывать:
без авторизации вернётся страница входа, а не файл.
