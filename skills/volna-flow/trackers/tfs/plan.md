# TFS · plan — пометить задачу активной

Открывается на `plan` при профиле `трекер: tfs`. Профиль `трекер: нет` или `mode: local` —
шага нет вовсе: статус ставить некуда.

Путь до CLI:

```
ls -d ~/.claude/plugins/cache/volna/volna/*/bin/volna-tfs.mjs | sort -V | tail -1
```

## Команда

```
node <плагин>/bin/volna-tfs.mjs state <id> Active
```

- статус ставится на баг или стори (номер из `state.json`): задача-фикс появится только на
  `deliver`;
- задача уже `Active` или `Resolved` → сказать об этом человеку и оставить как есть;
- допустимые состояния и причины перехода показывает `states <тип>`.
