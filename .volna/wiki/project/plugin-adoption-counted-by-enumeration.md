# Перенятая практика считается внедрённой только после перечисления компонентов

**тип:** приём · **предмет:** охват правки по компонентам · **этапы:** implement, capture
**раздел:** project

**вывод:** правило вида «у каждого X есть раздел Y» закрывается не правкой, а **списком X**:
перед тем как пометить часть сделанной, компоненты перечисляются командой, и по списку видно,
где раздела ещё нет. Память об охвате врёт тем сильнее, чем больше файлов правилось подряд.

Наблюдалось на переносе практики «у компонента названа его граница»: строка `**Не делает:**`
легла во все 27 команд и раздел «Чего этот скилл не делает» — в оба скилла `volna`, а семь
скиллов `volna-craft` остались без него. Часть задачи была помечена «сделано» с оговоркой про
другое сужение, и пробел нашёлся только при внешнем вопросе «все ли планы реализованы».

Перечисление стоит одну строку и годится прямо в свидетельства «Состояния»:

```bash
for f in skills/*/SKILL.md plugins/*/skills/*/SKILL.md; do
  grep -q "Чего этот скилл не делает" "$f" || echo "НЕТ $f"
done
```
