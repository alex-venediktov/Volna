# Дефекты флоу находит прогон по флоу, а не тесты и чтение кода

**тип:** направление · **предмет:** проверка выпускаемой версии · **этапы:** unit-tests, capture
**раздел:** project

**вывод:** синтетические фикстуры описывают **заполненное** состояние, а флоу ломается на
незаполненном. Поэтому версия проверяется живой задачей по самой «Волне», а не только прогоном
тестов.

Показательный случай: поле frontmatter без значения (`branch:` до создания ветки) заводило пустой
массив на случай блочного списка, список не приходил, а **пустой массив в JS истинен** - и
`if (fm.branch)` пропускал незаполненное поле дальше. Шапка печатала разделитель без значения на
пяти этапах из тринадцати, одинаково в `preamble` и `SessionStart`.

Дефект жил во всех версиях с появления hooks. Ни тесты его не видели (в синтетическом журнале
ветка всегда заполнена), ни чтение кода. Нашёлся **первым же сообщением** прогона флоу.

Следствие для тестов: чинить не только потребителей, но и разбор, а в фикстуры добавлять пустое
поле, пустой список и отсутствие секции.
