# Указатель раздела project

Указатель разбит по этапам: превышен порог объёма. Этап открывает только свой файл.

Маршрут выбирается по колонкам «предмет», «тип» и «описание»: открывать нужно один узел,
а не раздел. Подходит несколько - открывать по одному, начиная с ближайшего к задаче.

| Куда | Вид | Предмет | Тип | Этапы | Описание |
|---|---|---|---|---|---|
| [spec](INDEX--spec.md) | узел · 1 | скилл без напоминания, ядро в сессии | направление | spec, plan, implement | - |
| [plan](INDEX--plan.md) | узел · 9 | бюджеты объёма документации, замер always-on и on-invoke, класс решения при повторном дефекте | направление ×5, ограничение ×3, приём | spec, plan, implement, capture | - |
| [implement](INDEX--implement.md) | узел · 13 | правка поиска и её проверка, бюджеты объёма документации, запуск CLI и его тесты | направление ×7, ограничение ×3, приём ×2 | spec, plan, implement, advocate, unit-tests, capture | - |
