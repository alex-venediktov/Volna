# Проверка ссылок родится красной, если не вырезать код-спаны

**тип:** ограничение · **предмет:** линт документации репозитория · **этапы:** plan, implement
**раздел:** project

**вывод:** проход по markdown репозитория «Волны» находит три неразрешимые относительные
ссылки, и **все три - иллюстративные примеры внутри кода**, а не дефекты: образец локатора вики
в `.volna/wiki/volna/wiki-flat-layout-and-link-key.md:11` и в `docs/STATUS.md:785`, образец
картинки markdown в `docs/reference/tfs-rest.md:114`. Проверка, вырезающая ```` ``` ````-блоки
и `` ` ``-спаны до разбора ссылок, даёт ноль находок на чистом дереве.

Значит, порядок при заведении такой проверки: сначала вырезание кода, потом разбор ссылок.
Иначе первая же версия гейта падает на собственных документах, его отключают, и проверки
не остаётся вовсе.

Тот же приём нужен любому проходу по текстам плагина, где документация **показывает** синтаксис:
записи вики и `STATUS.md` цитируют форму локатора, файлы этапов - форму команд.
