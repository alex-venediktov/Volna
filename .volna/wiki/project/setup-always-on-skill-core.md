# Правило «без напоминания» держит hook ядра, а не описание скилла

**тип:** направление · **предмет:** скилл без напоминания, ядро в сессии · **этапы:** spec, plan, implement
**зона:** setup · **раздел:** project

**вывод:** скилл подхватывается по `description`, когда запрос похож на его зону («напиши README»),
и не подхватывается на обычном ответе в чате. Правило, которое должно действовать всегда, кладёт
в сессию hook `SessionStart`: он печатает раздел «Ядро» из `SKILL.md` и ссылку на полный скилл.
Так у ядра один источник, а правка раздела меняет то, что приходит в сессию.

- Ядро оплачивается в каждой сессии и в замер `claude plugin details` не входит: бюджет держит
  проверка длины в тесте hooks, а не инвентарь;
- hook срабатывает и вне репозиториев с `.volna/`, у подагентов `SessionStart` не срабатывает;
- правило о форме текста проверяется на самом ядре: первая редакция ядра humanizer запрещала тире
  вместо глагола и сама писала «тройки - только когда пунктов три».
