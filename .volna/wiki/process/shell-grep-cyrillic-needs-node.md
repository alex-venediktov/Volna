# Греп по кириллице в Git Bash режет буквы на байты - счёт по русскому тексту ведётся на Node

**тип:** ограничение · **предмет:** поиск по русскому тексту в shell · **этапы:** analyze, advocate
**раздел:** process

**вывод:** в Git Bash на Windows `grep -E` с классом `[А-ЯЁ]` и границей слова `\b` работает
по байтам, а не по буквам: `grep -o "[А-ЯЁ]{3,}"` выдаёт обрывки вроде «не», «по», «зада» вместо
слов в верхнем регистре, а `\bНЕ\b` не находит ничего. Выражение не падает и не предупреждает, поэтому
счёт выглядит правдоподобным. `awk length` по той же причине считает байты: кириллическая строка
в 90 знаков выходит длиннее 160.

Поиск и счёт по русскому тексту ведутся инструментом `Grep` среды или коротким скриптом на Node
(`fs.readFileSync(f, "utf8")`, длина строки - `[...line].length`). Для слова целиком в JavaScript
нужен `(^|[^\p{L}])` с флагом `u`, а не `\b`: там класс `\w` тоже ASCII.
