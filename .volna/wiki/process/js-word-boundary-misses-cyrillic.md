# Граница слова в регулярном выражении JavaScript не срабатывает на кириллице

**тип:** ограничение · **предмет:** разбор русского текста кодом · **этапы:** implement, unit-tests
**раздел:** process

**вывод:** `\b` в JavaScript опирается на класс `\w`, а он остаётся ASCII (`[A-Za-z0-9_]`) даже
с флагом `u`. Поэтому `/\bснята\b/iu` не совпадает **никогда**: между пробелом и `с` границы нет,
потому что кириллическая буква для `\b` не словесный знак. Проверка «слово целиком» на русском
тексте пишется через `(^|[^\p{L}])` с флагом `u` либо, когда ложное срабатывание внутри слова
невозможно, обычным вхождением подстроки.

Коварство в том, что выражение не падает и не предупреждает — оно просто не находит ничего,
и разбор молча возвращает «не названо» для каждой строки.
