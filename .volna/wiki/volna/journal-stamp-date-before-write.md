# Вызов `date` и запись секции одной командой дают метку на глаз

**тип:** порядок · **предмет:** метки времени в журнале · **этапы:** analyze, spec, plan, implement, advocate, unit-tests
**раздел:** volna

**вывод:** секция лога, дописанная heredoc'ом в той же команде, где спрашивается `date`, получает
метку, набранную **до** ответа часов: текст команды собирается целиком раньше, чем она запускается.
Наблюдалось в одном журнале дважды - метки ушли вперёд часов на 3 и на 11 минут, а ответ `date` в
выводе той же команды показывал верное время. Порядок - `date` отдельным вызовом, затем запись с
полученной меткой.

Проверка записи этого не ловит: hook метки висит на правках инструментами, а запись через shell
идёт мимо него. Ушедшую вперёд метку тогда называет только шапка следующего сообщения человека.

**источник:**
- `hooks/hooks.json:39` — `"matcher": "Write|Edit|MultiEdit",`

**проверено:** 2026-10-12
