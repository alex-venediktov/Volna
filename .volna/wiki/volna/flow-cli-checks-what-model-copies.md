# Модель передаёт в аргумент то, что показала человеку: составную часть проверяет CLI

**тип:** ограничение · **предмет:** аргументы CLI плагина · **этапы:** plan, implement
**раздел:** volna

**вывод:** когда текст команды показывает человеку полное имя (`<дата>-<slug>`), а в вызов просит
передать его часть (`--slug`), модель передаёт показанное целиком. Строка правила «только слова»
от этого не страхует: показанное стоит ближе к вызову, чем правило. Без отказа в коде
`volna-task add` молча заводит id с двумя датами, и ошибка видна только по готовым журналам.

Практический смысл: аргумент, который собирается в составное имя, CLI проверяет на присутствие
уже собранной части и отказывает кодом 1 без записи, называя годный вызов. Молча снимать
лишнее нельзя: так прячется расхождение между показанным человеку и переданным.
