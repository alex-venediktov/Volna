# Указатели вики собираются инструментом, ручная правка будет затёрта

**тип:** порядок · **предмет:** указатели вики · **этапы:** plan, capture
**раздел:** volna

**вывод:** `volna-wiki index --fix` строит указатели из самих записей. Дописывать строку в
таблицу руками не нужно и вредно - следующая сборка её сотрёт. Задача этапа `capture` - написать
запись и позвать сборку.

Указатель существует ровно затем, чтобы **стоимость чтения не росла вместе с накопленным
опытом**. Строка на каждый вывод, колонка «предмет» - чтобы этап отбирал строку, не открывая файл.

При росте корпуса указатель дробится по этапам, и этап открывает `<раздел>/indexes/<этап>.md`,
а не весь раздел: на живом корпусе это **8-160 строк вместо 329**. Ось дробления именно этап,
потому что этап читает только свою секцию.

Записи без поля `этапы` в указатель не попадают вовсе - для читающего этапа их нет.
