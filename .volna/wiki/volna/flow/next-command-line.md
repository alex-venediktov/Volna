# Последняя строка хода - команда без аргументов, иначе подсказка её не покажет

**тип:** ограничение · **предмет:** подсказка у поля ввода · **этапы:** analyze, plan, implement, deliver
**раздел:** volna

**вывод:** подсказку у строки ввода (`Tab` + `Enter`) Claude Code генерирует **сам**, отдельным
фоновым запросом по хвосту разговора. Ни скилл, ни hook её не задают: `UserPromptSubmit` умеет
только `additionalContext`. Влиять на неё можно единственным способом - содержанием ответа.

**Команду с пробелом внутри подсказка не показывает вовсе.** Поэтому `Дальше: /volna:skip
unit-tests` и `/volna:implement <что не так>` не давали ни подсказки, ни экономии набора. Вместо
них - команда конкретного следующего этапа без параметров, а причина возврата и что не сошлось
идут **текстом выше** строки: этап читает их оттуда.

Оговорка появилась на первом же применении: **нет следующего шага - нет и строки.** Без неё
правило заставляет придумать команду, и первым выводом стал бессмысленный `/volna:doctor`
в репозитории без проектной части. Гарантии тоже нет: в plan mode подсказка не генерируется.
